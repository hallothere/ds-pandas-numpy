| Goal                                    | Best Plot           |
| --------------------------------------- | ------------------- |
| Compare category → value                | **Bar chart**       |
| Show distribution of one variable       | **Histogram / KDE** |
| Compare distributions across groups     | **Box plot**        |
| Two continuous variables (relationship) | **Scatter plot**    |
| Change over time                        | **Line plot**       |
| Top-N values                            | **Horizontal bar**  |
| Correlations between many variables     | **Heatmap**         |
| Count categories                        | **Bar chart**       |
| Multivariate exploration                | **Pairplot**        |
